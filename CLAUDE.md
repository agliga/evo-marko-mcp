# evo-marko-mcp — notes for coding agents

- Zero runtime dependencies is a design goal: the server must start with `npx github:agliga/evo-marko-mcp` and no install step. Use only Node built-ins (Node >= 18.17).
- Never write to stdout from the server except protocol messages; log to stderr.
- `data/index.json` is generated by `npm run build:index` — do not hand-edit it. Regenerate and commit it after changing anything in `scripts/`.
- Run `npm test` before committing. Tests cover the parsers, the crawler (local HTTP server), every tool and the stdio transport.
- Component data comes from `eBay/evo-web` `packages/evo-marko` (Marko 6, `@evo-web/marko`), not `packages/ebayui-core` (Marko 5). Keep that distinction in tool output.
